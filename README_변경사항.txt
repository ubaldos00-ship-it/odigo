내용 — 통합 3단계 「나 조사하러 간다」 (설계: 설계/v2.4 10장)
 - 아래 버튼 「🚨 나 조사하러 간다」, 조사구 카드 「🚨 이 핀 위치 보내기」, 지도 임시 핀 「🚨 이 위치 보내기」
 - 누를 때 GPS 한 번 조회 → 미리보기: 현재 위치(주소·GPS 시각·정확도) / 조사 목적지, 각각 지도 링크
 - 보내기: 💬 카톡(카카오 공식 공유, 방은 직접 선택) · ✉ 문자(내 설정 번호, 보내기 전 수정 가능, 문구 먼저 복사) · 📋 복사
 - GPS 권한 거부·시간 초과·정확도 낮음(±100m 초과) 각각 안내 / 목적지만 보내기 / 지도에서 핀 찍어 보내기 / 마지막 확인 위치
 - 내 설정 › 현장 안전 연락: 기본 문자 번호, 카카오톡 안전 연락방 이름
 - 지도 링크: 문자·복사 = 카카오맵 링크 / 카톡 = 버튼 2개(현재 내 위치·조사 목적지) → 어디고 ?pin= 링크
   (카카오 공유는 등록된 도메인 링크만 허용) → 받는 사람이 누르면 어디고에서 그 위치 핀 + 카카오맵 열기 + 길찾기
 - 위치는 어디고 서버로 보내지 않음
