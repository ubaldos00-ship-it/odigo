내용 — 통합 4단계 + 엑셀
 - 업무별 자료 공유: ⓘ › 📤 업무별 자료 공유, 또는 분야 목록 아래 「📤 이 업무 자료 공유」
   범위 = 업무 전체 / 조사 유형 / 작물 / 하나씩 고른 조사구 → 건수 미리보기 → 암호화 파일(암호 2026)
   → 휴대폰 공유 메뉴(카톡 등). 공유 메뉴가 안 되면 파일 저장 + 공유 문구 복사
 - 자료 파일 가져오기: 보낸 사람·범위·새로/최신/이미 있음 미리보기 후 합치기 (틀린 암호·취소면 기존 자료 그대로)
 - 엑셀: 📄 양식 받기(.xlsx, 「안내」 시트에 쓸 수 있는 값) / 📥 엑셀로 조사구 올리기
   · 텐아르 조사구 양식(번호·시도·시군구·읍면동·리·본지번·부지번·층·조사구·초입주소·위도·경도·비고·메모)도 인식
   · 위도·경도 없으면 주소 또는 시도~지번으로 카카오 위치 찾기(배포 주소에서 동작)
   · 못 찾은 줄은 올리지 않고 행 번호 목록(복사 가능), 이미 있는 조사구는 건너뜀, 한 번에 3,000줄까지
 - 핀 모양·색·이름표: 과 단위 → 업무(조사 유형) 단위, 내 과 업무가 먼저 나옴(다른 과는 골라서)
 - 내 위치: 텐아르와 같게 — 파란 점·정확도 원·방향 부채꼴(폰 방향대로 돎)
   ① 현재 위치(북쪽 고정, 4m 이상 움직이면 따라감) ② 방향 추적(지도가 진행 방향으로 회전) ③ 해제, GPS 상태 표시
