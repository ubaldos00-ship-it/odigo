내용
 1. 지도를 길게 눌렀을 때 뜨는 팝업이 핀 아래로 가려지던 문제 → 팝업을 맨 위로
 2. 문자 받는 번호: 안전 연락 화면에서 한 번 넣고 보내면 기억해서 다음부터 자동으로 채움(내 설정에서도 수정)
    카톡 외 문자·복사 문구에 카카오맵 + 네이버지도 링크를 함께 넣음, 받은 위치 화면에도 「네이버지도에서 열기」
 3. 업무별 핀 모양(물방울·동그라미·네모·마름모·세모·별)·색 지정 (ⓘ › 내 설정 › 업무별 핀 모양·색·이름표)
 4. 핀 아래 이름표: 업무별로 조사명·이름·주소·층-카드·조사구번호·작물 중 골라 표시(지도 확대 15 이상)
    조사구 입력에 조사구번호·층·카드·구분(논·밭·대지·축사·응답자집·기타) 추가
 5. 분야 목록에 드롭다운: 시도 › 시군구 › 읍면동, 작물, 층, 조사구, 구분 (값이 있는 것만, 건수 표시)
 6. 핀 안 번호 = 같은 업무·조사 유형·작물·읍면동 안에서 조사구번호 순 번호. 오늘 방문 번호는 핀 오른쪽 위 빨간 표
 7. 내 위치 3단: ① 현재 위치로 이동·따라가기 → ② 방향(나침반)대로 지도 회전 → ③ 해제
 + 업무 탭(예: 재배면적)을 한 번 더 누르면 그 업무 핀만 지도에 남기고 다 보이게 축소(드롭다운 조건 포함)
