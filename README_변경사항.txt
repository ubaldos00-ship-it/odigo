내용 — 통합 2단계 「프로필·업무별 조사구」 (설계: 설계/v2.4)
 - 처음 접속: 닉네임(텐아르 게임 이름) + 주요업무분야 6개 중 하나 → 업무별 「나의 조사구 현황」
 - 현황: 조사 유형별 건수(0건 표시), 생산량은 전체+작물 15종 건수, 누르면 목록
 - 오른쪽 분야 버튼: 기본 분야 맨 위 + 농어업·경제·사회·대행, 지역·지원은 「⋯ 분야」 안
   (화면 높이 700 미만이면 기본 분야만 보이고 나머지는 ⋯ 안). 누르면 그 분야 핀만 + 목록
 - 조사구 등록·수정: 분야·유형·작물(생산량일 때)·이름·메모. 목록은 시도›시군구›읍면동›리(법정동)
 - 미분류(v2.3에서 옮겨 온 장소): 여러 건 골라 분야·유형 한꺼번에 지정
 - 조사구와 방문 기록 분리(같은 곳 여러 날 방문 가능)
 - 저장: 기기 금고형 암호화(IndexedDB 꺼낼 수 없는 키 + AES-GCM). v2.3 평문 자료는 처음 열 때
   자동으로 옮기고 다시 읽어 대조 → 일치하면 예전 자료는 7일 보관 후 삭제. 실패하면 예전 자료 그대로
 - 백업 파일: 암호화(암호 2026, 모든 사용자 공통). 예전 v2.3 백업도 불러오기 가능, 미리보기 후 합치기
 - 검색: 내 조사구를 먼저 보여 줌
