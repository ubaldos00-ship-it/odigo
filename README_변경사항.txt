내용 — 텐아르 핀 가져오기 (ⓘ › 텐아르 › 📍 텐아르 핀 가져오기)
 - 같은 휴대폰·같은 브라우저에 저장된 텐아르 자료를 찾아 농어업과 업무로 가져옴
   작물재배 조사구 → 재배면적(조사구번호·층), 가축 → 가축(축종·농장명은 메모), 축비 → 축비,
   농비 → 농비(지목이 논·밭·대지·축사면 구분으로), 쌀값 → 쌀값, 농판 → 농판, 기타조사 → 기타농업,
   생산량 핀(즐겨찾기) → 생산량(작물 포함)
 - 텐아르 자료는 읽기만 함(바꾸지 않음). 전화번호·담당자 연락처는 가져오지 않음
 - 종류별 건수·처음 가져오는 건수를 먼저 보여 주고, 고른 것만 미리보기 → 합치기
 - 다시 가져와도 겹치지 않음(같은 핀은 더 나중에 고친 쪽 내용이 남음), 위치 없는 핀은 제외
 - 다른 기기라면: 텐아르 조사구를 엑셀로 받아 어디고 「📥 엑셀로 조사구 올리기」
