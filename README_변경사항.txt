내용
 1. 조사구 삭제
    - ⓘ › 🗑 조사구 삭제: 모든 업무(전체) / 미분류 / 분야 / 조사 유형 / 작물 범위로 지우기
    - 「하나씩 골라서 지우기」(모두 선택 가능)
    - 분야 목록 아래 「🗑 이 업무 삭제」, 「🗑 골라서 삭제」 (보고 있던 업무·작물이 범위로 들어감)
    - 지울 건수 표시 → 「💾 먼저 전체 백업」 → 「삭제」라고 입력해야 지우기 버튼이 켜짐 → 한 번 더 확인
    - 방문 기록도 함께 지움, 내 설정(닉네임·핀 설정)은 남김, 되돌릴 수 없음
 2. 텐아르 앱 → 어디고 앱: ⓘ › 「📂 텐아르 파일 가져오기 (앱→앱)」 버튼을 바로 보이게
    (텐아르 앱 조사구목록 「🗄 전체 백업」·「📤 전체 공유」, 즐겨찾기 「공유」 파일 + 텐아르 암호)
